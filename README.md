# Генератор пушей

Веб- и Windows-версия генератора уведомлений для домофонов, шлагбаумов и обходов.

## Возможности

- выбор профиля: домофоны, шлагбаумы или обходы;
- поиск адреса по встроенному справочнику;
- даты и произвольные интервалы с одной или двумя границами;
- отдельные блоки выдачи ключей с датой, временем, местом и диапазоном подъездов жителей;
- ручные обозначения подъездов;
- четыре готовых текста с копированием и лимитом 2 000 символов;
- локальный редактор шаблонов;
- веб- и десктопная версии работают без учётной записи.

## Установка Windows

Скачайте `Intercom-Push-Generator-Setup-<версия>.exe` из [последнего релиза](https://github.com/bagrot/intercom-push-generator/releases/latest) и запустите его. Node.js, pnpm и другие инструменты разработки на компьютере пользователя не нужны: приложение, локальный сервер, адресный справочник и профили входят в установщик.

Установщик пока не подписан сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen.

В приложении отображается установленная версия и доступна проверка обновлений. Когда опубликован новый GitHub Release с установщиком, приложение показывает кнопку загрузки. Пользователь запускает скачанный установщик для обновления; автоматической установки без его участия нет.

## Публикация новой версии

Измените `version` в корневом `package.json` и `desktop-runtime/package.json`, зафиксируйте изменения, затем создайте и отправьте тег `v<версия>`. GitHub Actions соберёт Windows-установщик и опубликует Release. Имя тега должно совпадать с версией пакета. Релиз должен быть публичным, чтобы приложение могло проверить наличие обновления.

## Локальный запуск

```powershell
pnpm install
pnpm dev
```

Веб-версия работает без Supabase. Импортированные адреса и правки шаблонов хранятся в браузере данного устройства.

## Сборка

```powershell
pnpm build
pnpm build:desktop
```

Веб-сборка появляется в `dist/client`, установщик Windows — в `release`.

## Формат адресов

Импорт поддерживает XLSX, XLS и CSV. Пустые строки удаляются. Совпадающие названия адресов могут сохраняться как отдельные записи исходного справочника.
