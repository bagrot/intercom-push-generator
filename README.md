# Генератор пушей по домофонам

Веб- и Windows-версия генератора новостей и push-уведомлений по 10 сценариям. Интерфейс выполнен в стиле внутренних сервисов «Электронного дома».

## Возможности

- 10 сценариев из листа «Пуши НОВ» итоговой таблицы;
- поиск адреса по справочнику; для трёх сценариев адрес необязателен;
- импорт адресов из XLSX, XLS или CSV; реальные адреса в репозиторий не включены;
- даты и произвольные интервалы с одной или двумя границами;
- отдельные блоки выдачи ключей с датой, временем, местом и диапазоном подъездов жителей;
- ручные обозначения подъездов;
- четыре готовых текста с копированием и лимитом 2 000 символов;
- локальный редактор шаблонов и история версий;
- веб- и десктопная версии работают без учётной записи.

## Локальный запуск

```powershell
pnpm install
pnpm dev
```

Веб-версия работает без Supabase. Импортированные адреса и правки шаблонов хранятся в браузере данного устройства.

## Сборка

```powershell
pnpm build
pnpm build:desktop
```

Веб-сборка появляется в `dist/client`, установщик Windows — в `release`.

## Формат адресов

Импорт поддерживает XLSX, XLS и CSV. Читается первый лист и первый непустой столбец; заголовок `Адрес` распознаётся автоматически. Пустые строки и дубликаты удаляются.
