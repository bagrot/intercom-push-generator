Что нового в версии 0.2.2:

• Обновления загружаются прямо в приложении. После проверки файла запускается установщик — открывать браузер или проводник больше не нужно.
• Перед установкой показывается список изменений из релиза GitHub.
• Во время загрузки виден прогресс; при ошибке появляется понятное сообщение.
• Скачанный установщик проверяется по размеру и контрольной сумме SHA-256 из GitHub.
