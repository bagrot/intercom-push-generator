Что нового в версии 0.2.4:

• Приложение проверяет обновления в общей папке Яндекс Диска. Для проверки и установки больше не нужен доступ к GitHub.
• Новая версия и список изменений показываются в приложении. Установщик загружается и запускается без браузера и проводника.
• Перед запуском приложение проверяет размер и контрольную сумму скачанного установщика.

Для перехода с 0.2.3 на этот способ обновления установите 0.2.4 один раз вручную. Следующие версии приложение сможет получать из Яндекс Диска.
