Что нового в версии 0.2.3:

• Установка и обновление выполняются для текущего пользователя в одной папке. Мастер больше не предлагает выбрать второй режим установки, из-за которого появлялись дубли.
• После загрузки обновления приложение запускает установщик напрямую — браузер, окно «Сохранение» и проводник не открываются.
• Список изменений и ход загрузки доступны в окне проверки обновлений.

Если на компьютере уже есть отдельная старая версия, установленная для всех пользователей, её потребуется удалить один раз через настройки Windows.
