Тестовая сборка текущего генератора пушей для macOS: профили «Домофоны», «Шлагбаумы» и «Обходы» в одном приложении.

Universal DMG рассчитан на Mac с процессорами Intel и Apple Silicon. Сборка не подписана сертификатом Apple Developer ID и не нотариализована; macOS может потребовать ручного разрешения запуска в «Системных настройках → Конфиденциальность и безопасность».

В этой сборке нет встроенной проверки обновлений для macOS. Кнопка Windows-обновлений не показывается.
