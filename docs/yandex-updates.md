# Выпуск обновления для Windows через Яндекс Диск

Публичная папка обновлений: https://disk.yandex.ru/d/yRC7UiZ1fFeR5A

1. Измените номер версии в `package.json` и `desktop-runtime/package.json`. Добавьте описание изменений в `release-notes/<версия>.md`.
2. На Windows в корне проекта запустите `pnpm build:desktop`. Команда создаст в папке `release` установщик `Intercom-Push-Generator-Setup-<версия>.exe` и `latest.json`.
3. В личном Яндекс Диске откройте папку «Генератор пушей». Сначала загрузите новый установщик и дождитесь завершения загрузки. Затем загрузите `latest.json`, подтвердив **«Заменить»**. Не переименовывайте файлы.
4. Проверьте обновление в уже установленном приложении кнопкой «Проверить обновления».

`latest.json` содержит версию, список изменений, размер и SHA-256 установщика. Приложение скачивает установщик только с Яндекс Диска и проверяет размер и SHA-256 перед запуском. Старые установщики можно оставить в папке; приложение выбирает файл по имени из `latest.json`.

Версия 0.2.4 — первая, которая проверяет Яндекс Диск. Более старые версии нужно один раз обновить вручную.
